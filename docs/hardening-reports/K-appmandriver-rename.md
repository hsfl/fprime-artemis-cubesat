# Worker K: Native App-Man-Drv Rename

Date: 2026-07-06

## BLUF

Repo-wide component nomenclature now uses native F' Application-Manager-Driver vocabulary:

- application tier components use `*App`
- manager tier components use `*Manager`
- driver tier components use `*Driver_<HardwareOrProtocol>`

Behavior was preserved as a rename-only refactor: base IDs and command opcodes remain numerically identical.

## Scope Notes

- Component directories and implementation/test filenames were renamed under `ArtemisRpiTeensy_N2/Components/`.
- `Top/instances.fpp`, `Top/topology.fpp`, and `Top/*TopologyDefs.hpp` use the new instance names.
- Active docs and runbooks now teach native application/manager/driver vocabulary.
- `docs/agents_notes.md` has a dated legacy mapping section so old logs stay decodable.
- `docs/*.mmd` sources were checked/updated. Rendered diagram assets should still be regenerated by the normal diagram pipeline.
- Teensy firmware workspaces were not intentionally modified.
- `git mv` could not be used because this sandbox cannot create `.git/index.lock`; filesystem `mv` was used instead. Git status therefore shows old component paths as deleted and new component directories as untracked until the orchestrator stages them.
